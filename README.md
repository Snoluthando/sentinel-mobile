Sentinel – Smart Crime Prevention & Community Safety Platform
Sentinel is a community-driven crime prevention and public safety application designed to improve communication, situational awareness, and coordination between residents, law enforcement, and private security services.

The platform provides users with a real-time view of reported criminal activity and safety concerns within their surrounding areas through an interactive mapping system. Residents can use Sentinel to report suspicious activity, criminal incidents, and potential threats, helping communities stay informed and proactive about their safety.

A key component of Sentinel is its integration of public safety awareness with security patrol visibility. By providing information about nearby police and private security patrols, the platform aims to improve coordination, encourage faster responses, and strengthen the relationship between communities and security providers.
Core Features
- Interactive Crime Map: Displays reported incidents and safety-related activity geographically.
- Incident Reporting: Allows community members to report crimes, suspicious behaviour, and other safety concerns.
- Security Patrol Awareness: Provides visibility into police and private security patrol activity.
- Community Safety: Encourages residents to participate in crime prevention through shared information.
- Location-Based Awareness: Helps users identify potentially unsafe areas and remain informed about nearby incidents.
- Centralised Dashboard: Provides an organised overview of safety information and platform activity.
Project Vision
Sentinel aims to move communities from reactive crime reporting towards proactive crime prevention. By combining location-based technology, community participation, and security awareness, the platform seeks to create a more connected, informed, and safety-conscious environment.
